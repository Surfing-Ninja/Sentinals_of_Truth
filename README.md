# Sentinels of Truth

## SQLite Note
SQLite was selected for lightweight local persistence and rapid prototyping within assignment constraints.

## Deployment Overview
- Frontend: Vercel
- Backend: Render

## Environment Variables
Backend:
- TAVILY_API_KEY
- ALLOWED_ORIGINS (comma-separated, e.g. https://your-frontend.vercel.app)

Frontend:
- VITE_API_URL (e.g. https://your-backend.onrender.com)
